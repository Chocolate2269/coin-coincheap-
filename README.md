# Concheap Investment

A modern crypto investment platform. Invest smart, start small.

## Live Demo
- [Main Site](https://chocolate2269.github.io/concheap-investment/)
- [Admin Panel](https://chocolate2269.github.io/concheap-investment/admin.html)

## Features
- User registration & login (Firebase Auth)
- Investor dashboard with balance
- Admin panel to manage users and add funds
- Live chat support (Chatway)

## Tech Stack
- HTML, Tailwind CSS
- Firebase Authentication
- Firestore Database
- GitHub Pages / Firebase Hosting
